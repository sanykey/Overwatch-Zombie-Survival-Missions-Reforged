## Два центральных луча спутника одним циклом

В `fireSatelliteMacro` файла `src/objective_types/objective_type_satellite_uplink.opy` два последовательных блока создают центральные вращающиеся лучи. Первый использует направление `directionFromAngles(getTotalTimeElapsed() * 360, 0)`, второй — это направление, умноженное на −1. Оба соединяют высоты +700 и −700 относительно satelliteLaserPosition; после каждого создания его ID добавляется в objectiveEntityIdList.

Два блока заменены следующим циклом:

```python
    # Two rotating center beams, preserving creation order: positive, then negative.
    # Only the side is captured; laser position and rotation keep reevaluating.
    # Scratch is dead after both Create Beam actions; the shaft loop reuses tmp0 below.
    #!define satelliteCenterBeamSide tmp0
    for satelliteCenterBeamSide in range(1, -2, -2):
        createBeam(getAllPlayers(), Beam.BAD, satelliteLaserPosition + 700 * Vector.UP + directionFromAngles(getTotalTimeElapsed() * 360, 0) * evalOnce(satelliteCenterBeamSide), satelliteLaserPosition + -700 * Vector.UP + directionFromAngles(getTotalTimeElapsed() * 360, 0) * evalOnce(satelliteCenterBeamSide), Color.SKY_BLUE, EffectReeval.VISIBILITY_POSITION_AND_RADIUS)
        objectiveEntityIdList.append(getLastCreatedEntity())
```

Цикл выполняется два раза, со значениями 1, −1. Порядок создания и регистрации эффектов сохраняется. `evalOnce` фиксирует только знак отдельно для обоих концов луча. Позиция лазера и вращение по Total Time Elapsed остаются живыми; режим переоценки, цвет и тип луча сохраняются.

Используется существующий глобальный tmp0 через смысловой алиас. Между чтением стороны, созданием луча и регистрацией его ID нет ожиданий или вызовов. Сразу после двух лучей следующий цикл световых столбов заново инициализирует tmp0. Предыдущий цикл лучей от терминалов уже завершён, его сохранённые ссылки используют собственные Evaluate Once. Новых переменных, правил, подпрограмм и ожиданий нет.

Исходные два блока стоят 72 элемента: лучи 32 и 38, две регистрации по 1. Общий цикл стоит 48: For 4, Create Beam 42, регистрация 1, End 1. Экономия — **24** по полной компиляции.
