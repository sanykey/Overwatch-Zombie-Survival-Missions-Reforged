# Постепенный перенос experiments

Ветка: `experiments-rebuild`.

База: `30bddc91ecd0465f0b2bb2824d37ea00ccf40a91` — Apothecary,
проверенная пользователем как `01-parent.ws.txt`.
Источник последующих изменений: исходная ветка `experiments`,
`9640f50049f7cce3e4e78265a9c80a7f71f03191`.

Bolt Strike и `beamEffects` не переносим. Механизм смены героя оставляем базовым.
Утечка/повреждение памяти Workshop остаётся гипотезой: журнал показывал
восстановление Allowed Heroes, несмотря на исчезновение новых героев на экране.

## Порядок работы

- Один небольшой исполняемый шаг — один коммит с обновлённым `main.ws.txt`.
- После каждого такого коммита ждать результата проверки в игре; без него
  не переносить следующую часть. Сборка без предупреждений не заменяет игровой тест.
- Для каждого шага измерять элементы Workshop и проверять фактический diff.
- Исправления меню, цвета, описания и оптимизации переносить отдельно от механик.
- Делить по минимальным завершённым изменениям: захват зомби без гарантированного
  освобождения или выбор ещё не реализованного улучшения не являются безопасными шагами.
- Не копировать устаревшие промежуточные реализации, если в исходной ветке они
  заменены. Leech переносить как Augment, Dead Weight — как Enhancement.
- Артефакты игровых проверок хранить в игнорируемой папке `experiments/rebuild/`.
  Старые диагностические скрипты и артефакты не включать в коммиты переноса.

## Очередь следующих небольших изменений

Каждый пункт — отдельный шаг; зависимый пункт выполнять только после проверки
предыдущего. При обнаружении дополнительных независимых изменений дробить дальше.

1. Apothecary: скорость +30% -> +50%, включая симметричное снятие и актуальный текст.
2. Grapnel Launcher: опрокидывание воздушной цели на 3 с, наземное оглушение прежнее.
3. Overcharge: начисление энергии от аптечек без двойного учёта.
4. Long Reach: применение подготовленного бонуса Overcharge к расширенным попаданиям.
5. Overcharge: предел расхода на разряд 250 -> 100, отдельно от помощи союзникам.
6. Overcharge: +10 энергии за assist с корректной начальной отметкой счётчиков.
7. Apothecary: заряд ультимейта +5% -> +7%.
8. Apothecary: длительность бонуса 3 -> 5 с.
9. Apothecary: возможность подобрать аптечку при полном здоровье.
10. Кэширование иконок: отдельно измерить каждую таблицу и её потребителей.
11. Изменения HUD: по одному расположению/объединению строк, без добавления механик.
12. Laser Barricade: точная проверка состояния прицеливания -1 вместо <0.
13. Подготовка выдачи/сброса powerups для Scavenger с сохранением базового поведения.
14. Scavenger: два резервных слота, подбор и гарантированный сброс; HUD и выбор согласованы.
15. Scavenger: отдельное правило 5% добычи при устранении бота.
16. Leech Augment: 15% вампиризма и +50 восстанавливаемого здоровья.
17. Dead Weight: слоты владения и захват с гарантированным освобождением,
    согласованная обработка Interact и прерываний.
18. Dead Weight: отдельный урон после броска, затем отдельные изменения HUD.
19. Оставшиеся цветовые/текстовые изменения и руководства — отдельными коммитами.

После каждого шага сверять цель с исходной веткой; порядок можно уточнять
по зависимостям, не объединяя независимые изменения в один исполняемый коммит.
