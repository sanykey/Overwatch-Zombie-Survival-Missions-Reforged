# Ошибка импорта: вложенные Any/All в Living Projectile

В пользовательском тесте после коммита `b2c1adf7b077e0d797fe6deb686cb6715c2201b0` игра сообщает: "Cannot nest more than 1 level for some of the values in this script."

Проблемное изменение — второе Condition правила `LIVING PROJECTILE RELEASE` в `src/abilities/enhancements.opy`. Внешний singleton `.any(lambda carrier: ...)` оборачивает `livingProjectileValid(carrier)`, который раскрывается в `.all()` массива validity-флагов. OverPy 9.7.21 компилирует это без предупреждений, но игровой импортёр отвергает вложенность. Анализ области видимости Current Array Element из предыдущего отчёта не проверял это ограничение импортёра.

Упрощённая форма ошибочного экспорта:

```text
Is True For Any(Array(carrier), Or(throwRequested, Not(Is True For All(Array(validityFlags), Current Array Element))))
```

Исправление возвращает исходное выражение Condition до коммита, без внешнего Any. Сам макрос validity, отдельное условие carrier != Null, все Actions освобождения, задержка перед уроном и атрибуция урона сохраняются. Остальные изменения коммита — постоянное здоровье Boss/Egg — остаются.

## Проверка

Запуск из корня: `node analysis/2026-11-18-validate-living-projectile-import-fix.cjs`.

Скрипт компилирует родителя проблемного коммита, сам коммит, текущий HEAD `998c18b` и фактический main.opy. Консервативная проверка вложенности даёт:

| Версия | Вложенные операции в предикатах |
| --- | ---: |
| До b2c1adf | 0 |
| b2c1adf | 1: All внутри предиката Any |
| HEAD перед исправлением | 1: та же пара |
| Фактическая исправленная сборка | 0 |

В исходной и текущей ошибочной сборках единственная найденная пара находится в LIVING PROJECTILE RELEASE. В исправленной сборке все Conditions этого правила совпадают с версией до проблемного коммита. Его Actions совпадают с текущим HEAD, остальные нормализованные правила и объявления переменных не изменены.

Итог: **30 005 → 30 011 элементов (+6)**, без предупреждений OverPy. Это отмена несовместимой оптимизации, а не новая оптимизация. Обновлён локальный main.ws.txt. [Машинный результат](2026-11-18-living-projectile-import-fix.json).

[Проверка вложенности](2026-11-18-workshop-predicate-nesting.cjs) различает операции в предикате и последовательную цепочку через аргумент массива: Sorted Array(Filtered Array(...), ...) не считается вложенным предикатом. Самопроверки покрывают ошибочную пару Any/All, цепочку Filtered/Sorted, вложенный Filtered внутри Mapped, строки и комментарии. Это проверка конкретного класса ограничений, не полная эмуляция импортёра.

Импорт исправленного файла в игру здесь не выполнялся. Нужно повторить импорт main.ws.txt и проверить удержание, бросок и аварийное освобождение Living Projectile. Исправление перенесено в переписанную версию исходного коммита; последующие коммиты пересобраны и переименованы с фактической экономией. Ссылки badRef и baselineRef в проверке намеренно указывают на сохранённую исходную историю для воспроизведения дефекта.
