## Генерация сетки

В `src/core/global_startup.opy`, подпрограмме `generateMapGrid`, используется:

```text
if mapGridList == [] or mapGridList.all(lambda x: distance(x, mapGridCandidatePosition) > 2.5):
```

Предлагается оставить только all(). Native Is True For All возвращает True для пустого массива — это подтверждено [публикацией автора проверки на форуме Blizzard](https://us.forums.blizzard.com/en/overwatch/t/wiki-workshop-syntax-script-database/335011?page=8). Это сообщение об игровом тестировании, а не новый тест текущей версии игры в рамках этой работы.

mapGridList явно инициализируется пустым массивом в начале подпрограммы, затем пополняется позициями. Для пустого списка и старый, и новый предикаты допускают первую точку. Для непустого списка сравнение с [] ложно, поэтому оба предиката сводятся к тому же all(). Не меняются предикат расстояния, порядок точек, Append To Array, случайные вызовы, ограничение 900, проверки комнат спавна и все ожидания.

В Workshop-экспорте условие уменьшается с 17 до 11 элементов. Полное нормализованное правило совпадает с базой после единственной замены `Or(Compare(Global.mapGridList, ==, Empty Array), P)` на P, где P — прежний Is True For All. Никаких других Actions или переходов менять не требуется.
