# Long Reach: устранение лишнего двойного прыжка

Причина: `DASH DOUBLE TAP` продолжал безусловный цикл после смены Augment,
включая смену выбора в меню. Его ожидания нажатия/отпускания не прерываются
изменением условий правила. После следующей пары нажатий вызывался
`useAugmentAirAction`, где ветка `else` давала двойной прыжок любому Augment,
кроме Dash. Она также перезаписывала общие слоты состояния Long Reach.

Ветка прыжка теперь явно требует `Augment.DOUBLE_JUMP`. Цикл Dash повторяется
только при сохранении условий правила. Новых переменных и ожиданий нет.
Действия самого Dash не изменены. Из остальных правил изменены только эти два.

Проверка: `node analysis/2026-11-13-verify-augment-jump-isolation.cjs`.
На исходном коде воспроизведён лишний прыжок Long Reach и перезапись его отката.
На исправленном коде проходят 28 сценариев: смена Dash на каждый из остальных
Augments, кроме Double Jump, во время каждого из трёх ожиданий ввода; завершение
старого цикла; сохранение чужих слотов; штатный Double Jump и его откат.
Это исполнение скомпилированных действий в модели, без проверки в игре.

Сборка: **30 120 → 30 126 элементов (+6)**, без предупреждений. Добавлены
проверки принадлежности обработчиков; циклические проверки Dash после смены
выбора прекращаются. Измерения скорости в игре не проводились.
Корневой `main.ws.txt` пересобран; файл исключён из Git настройками проекта.

Общий `node analysis/verify-augments.cjs` останавливается на проверке телепорта
Apothecary (строка 556). Та же ошибка подтверждена на исходном `augments.opy`
из HEAD; исправление прыжка её не меняет.
