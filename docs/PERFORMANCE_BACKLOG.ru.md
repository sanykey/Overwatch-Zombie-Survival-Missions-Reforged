# Оставшиеся оптимизации Workshop

Сверено 22 ноября 2026 года с `stability-rebuild` на `d81b6d2`. База для новых сравнений — 29 847 элементов в обычной сборке и 29 840 в perf-профиле. Здесь собраны открытые предложения из обсуждения, актуальные пункты [аудита кода](CODE_REVIEW_REPORT.ru.md) и кандидаты на точечный перенос из [аудита `main`](MAIN_COMMIT_PENDING.md). Число элементов и `Server Load` измеряются отдельно. Связь этих находок с падениями пока не подтверждена игровым прогоном.
