# Zombie Survival Missions Reforged 2.0

**ZSM Reforged** — мод для Overwatch Workshop, созданный как переработка **Zombie Survival Missions Modded (ZSMM)** от **Kamenrider#11346**. За основу взят снимок версии **786TW** от **30 октября 2026 года**. Оригинальную Zombie Survival Missions создал **Mazattack#1183**. [Zombie Survival Missions Modded (786TW)](https://workshop.codes/786tw)

## Как использовать код мода

Для компиляции исходников в код Workshop используется [OverPy](https://github.com/Zezombye/overpy), в репозитории которого также доступна документация по языку. Точка входа для компиляции — файл `main.opy` в корне проекта. Удобнее всего использовать расширение OverPy для Visual Studio Code.

1. Установите Visual Studio Code и расширение OverPy по [инструкции по установке](https://github.com/Zezombye/overpy#installation).
2. Откройте папку проекта в VS Code, затем корневой файл `main.opy`.
3. Сохраните `main.opy` (`Ctrl+S`). Расширение запустит компиляцию; при успешной сборке готовый код окажется в буфере обмена и в файле `main.ws.txt` в корне проекта.
4. В Overwatch создайте пользовательскую игру, откройте её настройки и импортируйте скомпилированный код из буфера обмена.

После изменения исходников снова сохраните корневой `main.opy`, чтобы получить обновлённый код мода.

### Проблема с пассивной регенерацией

Пассивная регенерация здоровья для команды зомби отключена в **Settings → Heroes → General → Team 2**. Однако при импорте исходного кода в Workshop эта настройка сбрасывается, предположительно из-за ошибки самого Workshop. **После каждого импорта кода вручную отключайте пассивную регенерацию для Team 2**, прежде чем публиковать короткий код мода.

## Геймплейные отличия ZSM Reforged от ZSMM (**786TW**)

### Выбор способностей перед матчем

- У каждого выжившего теперь два независимых слота способностей. Основное усиление (**Enhancement**) выбирается кнопкой **Quick Melee**, аугмент (**Augment**) — кнопкой **Interact**. Доступно **14 усилений и 9 аугментов**.
- Если оставить **No Preference**, игра назначит случайный вариант, в том числе при входе в уже начавшийся матч.

### Бой, зомби и предметы

- **Во время ультимейта игрок получает на 35% меньше урона.** Укусы зомби не добавляют стаки заражения и не накладывают периодический урон, а атаки зомби не поджигают игрока. Уже наложенные эффекты продолжают действовать.
- **Танки наносят на 10% меньше базового урона, герои урона — на 5% меньше.**
- **Carrion (Jetpack Cat)** — новый обычный зомби. Он атакует с воздуха, может использовать ультимейт, а другие зомби могут запрашивать у него перевозку. Появляется в **All Zombies**, **New Blood** и **What’ll it be?**
- **Cure+ объединяет Cure и Vaccine.** Предмет снимает активное заражение. Если игрок не заражён, он получает **1,5 уровня защиты** от будущих укусов.
- **Bounce Pad** удалён из списка расходников.
- По умолчанию в матче **7 зомби вместо 6**, а в ящике снабжения **6 предметов вместо 5**.

### Изменения героев

- **Солдат-76** наносит на **50% больше урона**, пока активен «Тактический визор».
- **Кэссиди** оглушает попаданием гранаты на **0,8 с**.
- **Бригитта** оглушает ударом щита на **0,8 с**.
- **Райнхардт** оглушает цель на **0,6 с**, если наносит ей урон с поднятым щитом.
- **D.Mon** оглушает цель на **0,6 с**, если наносит ей урон способностью **Surging Strike**.

### Задания и эвакуация

- **Завершение задания даёт больше времени на спасение.** К активному таймеру каждого игрока в состоянии **Down** прибавляется полный текущий лимит спасения, от **30 до 60 с**. Например, остаток **12 с** при лимите **60 с** превращается в **72 с**.

### Камера и игровой HUD

- **Reload + Crouch + Jump** переключает обычную камеру и камеру от третьего лица. Расстояние до камеры зависит от размера героя. У **Аны, Эш, Роковой Вдовы, Эмре и Фрейи** прицеливание временно возвращает стандартную камеру.
- В командном HUD теперь видны значки обоих усилений.
- Обновлён HUD способностей. Он показывает заряды, время до готовности и подсказки по управлению. Цвет названия способности меняется в зависимости от её состояния.
- Во время игры отображаются выбранные **Challenge** и **Zombie Mod**.
