# Overwatch Zombie Survival Missions Reforged

Переработка режима [Zombie Survival Missions](https://workshop.codes/786TW) для мастерской Overwatch на основе **ZSMM (786TW)**. Исходная версия сохранена в каталоге [ZSM examples/ZSMM (786TW)](<ZSM examples/ZSMM (786TW)>).

Цель проекта — максимально сократить количество элементов скрипта и убрать лишнее, чтобы освободить место для новых механик и улучшений героев. На первом этапе работа сосредоточена на технической оптимизации; по мере развития проекта здесь будут появляться конкретные изменения игрового процесса.
