# Overwatch Zombie Survival Missions Reforged

[English](Readme.md) | **Русский**

Переработка мода [Zombie Survival Missions (786TW)](https://workshop.codes/786TW), написанная на языке [OverPy](https://github.com/Zezombye/overpy). Основой Reforged служит [снимок ZSMM (786TW) от 30 октября 2026 года](<workshop-snapshots/ZSMM (786TW)/2026-10-30 ZSMM (786TW).ow>).

Цель проекта — максимально сократить число элементов оригинального мода, чтобы освободить место для новых механик. Первый этап посвящён технической оптимизации. Изменения игрового процесса будут описываться здесь по мере их появления.

Скомпилированный код актуальной версии мода находится в файле [main.ws.txt](main.ws.txt). Скопируйте его содержимое и импортируйте в Overwatch Workshop.

BattleTag автора Reforged: **snky#21990**.

В ветке [zsmm-classic](https://github.com/sanykey/Overwatch-Zombie-Survival-Missions-Reforged/tree/zsmm-classic) будут публиковаться только оптимизации и исправления классического [Zombie Survival Missions (786TW)](https://workshop.codes/786TW) с сохранением исходных игровых механик. Ветка `main` предназначена для дальнейшего развития Reforged, включая добавление нового функционала.

## Как использовать код мода

Для компиляции исходников в код Workshop используется [OverPy](https://github.com/Zezombye/overpy), в репозитории которого также доступна документация по языку. Точка входа для компиляции — файл `main.opy` в корне проекта. Удобнее всего использовать расширение OverPy для Visual Studio Code.

1. Установите Visual Studio Code и расширение OverPy по [инструкции по установке](https://github.com/Zezombye/overpy#installation).
2. Откройте папку проекта в VS Code, затем корневой файл `main.opy`.
3. Сохраните `main.opy` (`Ctrl+S`). Расширение запустит компиляцию; при успешной сборке готовый код окажется в буфере обмена и в файле `main.ws.txt` в корне проекта.
4. В Overwatch создайте пользовательскую игру, откройте её настройки и импортируйте скомпилированный код из буфера обмена.

После изменения исходников снова сохраните корневой `main.opy`, чтобы получить обновлённый код мода.
